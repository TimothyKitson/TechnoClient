Features

Everything you need, nothing that gets you banned

Built on the best performance mods out there, plus our own HUD. No cheats, ever.

Way more FPS

Sodium rewrites how chunks are drawn, and Lithium speeds up game logic. Built-in laptop graphics often run a lot faster.

Tunes itself

Checks your graphics card and RAM on first launch and picks Potato, Balanced or High. Change it anytime with Right Shift.

No more freezes

FerriteCore cuts memory use, and the installer gives Minecraft the right amount of RAM for your laptop. That fixes the "0 FPS for a few seconds" stutters.

Purple HUD

FPS, CPS, ping, coordinates and keystrokes in a clean purple-and-black style. Turn each part on or off.

Smooth zoom

Hold C to zoom and scroll to zoom further. Mouse sensitivity drops while zoomed so aiming stays steady.

Purple block outlines

Install

Three steps and you're playing

You need Minecraft: Java Edition and the normal Minecraft Launcher. Void Client adds itself to the launcher you already have.

Download and open

Get VoidClient-Installer.exe and open it. Close the Minecraft Launcher first.

Press Install

It downloads every mod straight from Modrinth, checks each file, and sets the right RAM for your laptop.

Pick Void Client and play

Open the Minecraft Launcher, choose Void Client next to the Play button, and press Play.

For the smoothest FPS

  • Plug in the charger. Laptops slow down on battery.
  • Close Chrome and other apps, especially on 4 GB laptops.
  • Power mode → Best performance in Windows Settings → System → Power.
  • Gaming laptop? If Void Client says it's on built-in graphics, set Java to High performance in Windows Settings → Display → Graphics.

FAQ

Questions

Windows says "Windows protected your PC". Is it safe?

That warning shows for new apps that haven't built up a download history with Microsoft yet. Click More info, then Run anyway. The installer only adds a Void Client profile to your Minecraft Launcher and downloads mods from Modrinth. Its source code is public.

Will I get banned on servers?

It shouldn't get you banned. Void Client has no X-ray, reach, autoclicker, kill aura, fullbright or minimap radar, and it never sends anything to servers. Coordinates hide themselves on servers that turn on reduced debug info. The mods inside are the same kind big servers like Hypixel allow. If a server lists banned mods, give it a quick check.

Does it work on school laptops?

It installs without admin rights, into your own user folder. Some schools block new apps or downloads from certain sites. If the installer can't download, try again on home Wi-Fi.

Where are my worlds and servers?

Void Client keeps its own folder at %APPDATA%\.voidclient, so it never touches your normal Minecraft. Your server list is copied over the first time. To bring a world, copy it from %APPDATA%\.minecraft\saves into %APPDATA%\.voidclient\saves.

How do I update?

Download the newest installer and press Install again. It swaps in new mod versions and leaves your worlds, settings and any extra mods you added alone.

How do I uninstall?
  1. In the Minecraft Launcher, open Installations and delete Void Client.
  2. Delete the folder %APPDATA%\.voidclient (paste it into the File Explorer address bar).
I use Prism Launcher or the Modrinth App.

Download the VoidClient.mrpack and import it as a new instance. Set the memory to 2 GB on a 4 GB laptop, 3 GB on 8 GB, or 4 GB on 16 GB.
